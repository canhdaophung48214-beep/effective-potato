# A+B 三屏静态 UI 原型实施计划

> 本计划在隔离报告目录执行，不修改正式项目，不提交 Git。

**Goal:** 基于参考图实现可运行的微信小程序首页、历史菜单列表和详情三屏，同时保持 39 条历史数据的价格与证据语义。

**Architecture:** 复制既有 `adapted_records_39.json` 作为只读侧车数据；`lib/menu-model.js` 负责搜索、排序、详情选择和安全展示模型；三个页面只消费展示模型。通用卡片、搜索栏、历史状态提示做成组件，所有导航和筛选均为本地静态交互。

**Tech Stack:** 微信小程序原生 WXML/WXSS/JavaScript，Node.js `assert` 离线测试，微信开发者工具（可用时）。
