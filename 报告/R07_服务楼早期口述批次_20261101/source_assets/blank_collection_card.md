## 一、你要做的三件事


| 顺序  | 做什么                         | 花多久   |

| 1   | **拍照**：窗口招牌 1 张 + 完整价目表 1 张 | 3 分钟  |

---

## 二、拍照只要满足 4 条

- ✅ **拍全**：价目表从头到尾都在画面里，不能只拍一半
- ✅ **看得清**：能认出每个菜名和价格（可以在手机上放大检查一下）
- ✅ **别反光**：避开灯管直射，稍微斜一点拍
- ✅ **横着拍**：手机横过来，一张照片装下整个价目表

拍不清就多拍两张，**不要猜价格**，看不清的那道菜直接空着。

---

## 三、抄这张小表（一个窗口一张）

把下面这几行抄到微信文件传输助手 / 便签里，照着填就行：

```
窗口名：（牌子上写什么就写什么，比如"猪脚饭·面"）
档口位置：（几楼、大概哪个位置，比如"2 楼靠楼梯口"）
拍照人：（你的代号就行，比如"小林"）
日期：（哪天拍的，比如 11 月 3 日）

菜名 | 价格 | 主食类型 | 辣不辣 | 备注
-----|------|----------|--------|------
（示例）某菜 | 12 元 | 米饭 | 不辣 | 这一行是示例，删掉
     |      |      |        |
     |      |      |        |
     |      |      |        |
```

**每一列怎么填（都是大白话，不用选代码）**


| 列    | 怎么填                                  | 举例                 |
| ---- | ------------------------------------ | ------------------ |
| 菜名   | 价目表上印的名字，原样抄                         | `红烧肉盖饭`、`卤肉面`      |
| 价格   | 只写数字 + 元                             | `12 元`、`8.5 元`     |
| 主食类型 | 米饭 / 面 / 米线 / 粉 / 饺子 / 麻辣烫 / 小吃 / 其他 | `米饭`               |
| 辣不辣  | 不辣 / 微辣 / 麻辣                         | `微辣`               |
| 备注   | 有就写，没有就空着                            | `可以免费加饭`、`大份 15 元` |


> 一道菜有两个价格（小份/大份、加蛋/不加蛋）→ **拆成两行**，各写各的价。

## 四、这 5 件事不要做

1. 不要猜价格 —— 看不清就空着
2. 不要把套餐、饮料、"加料 1 元"当成一道菜录
3. 不要写自己的真名、学号、手机号（代号就行）
4. 不要把一个窗口的菜算到另一个窗口头上
5. 不要美颜 / 压缩 / 裁照片，**原图**发我
