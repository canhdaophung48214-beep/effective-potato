## 4. 为什么窄屏仍是 PENDING（已尝试的路径）

| 尝试 | 结果 |
|---|---|
| 微信开发者工具 CLI | `cli open/auto --help` 均无 `--device`/`--viewport` 参数 |
| 自动化协议 | 连接 `ws://127.0.0.1:9435` 可用（`App.getCurrentPage/callFunction/callWxMethod/captureScreenshot`）；但 `App.setDevice`、`App.setViewport`、`Tool.setDevice`、`Emulator.setDevice/resize`、`Device.setDevice` 全部返回 `unimplemented`；`Tool.getInfo` 可用（2.02.2608080 / SDK 3.7.12） |
| IDE 窗口 UI 自动化 | 当前 DevTools 进程（PID 14088）无主窗口标题，UIAutomation 顶层窗口列表里没有开发者工具窗口，无法点选机型下拉框 |
| 配置文件 | `mini/` 内无 `deviceType/phoneType` 等机型键；DevTools 的机型属于 IDE 本地状态，不在项目配置里 |

结论：**机型切换只能由人在 IDE 模拟器顶部的机型下拉框中完成**，自动化无法代劳；因此不把窄屏判 FAIL，也不假装 PASS。
