## 二、「去暂定」改变什么、不改变什么（边界，防误读）

去暂定**仅**是名称层面的转正：名册显示名、`shops.csv` 潜在名称、B8 blocker 状态。

去暂定**不**改变：

1. `verifyStatus` / `verifiedAt`——全体记录仍 `unverified`；
2. tier 与 dishId 区间——已分配的 d437–d540 不动；
3. `import_eligibility = blocked`——其依据是正式 `stallId` 未下发（契约 `:511`），与名称无关；
4. W2-04 §8.3 整项核验状态——DR-2F09 负面清单已明列「W2-04 整项核验」不在该 DR 确认范围；
5. 历史记载——转录稿 `:739` 等原文不动（就地注记留痕原则，同「蛋」字轮先例）。

## 三、转正条件（通用规则）

满足**任一路径** + 全部**共同后置**，方可转正。

### 路径 A：证据确认

归档照片（档口招牌 / 导览牌）上可读出与拟用名一致的实名，**且负责人亲验归档件**
（亲验＝第 0 步，先例见「蛋」字更正轮）。

### 路径 B：负责人声明

负责人明确声明该档口正式名，并**指明声明覆盖哪些记录来源**（如「W2-04 三张照片
全部同属该店」）。既有先例：

- **W2-16 欣达快餐**：转录稿 `:868`「门头照：继续列为待补证据，**不阻断已由用户确认的名称使用**」、`:816`「店名与名册归属已确定；门头照作为补证项」——名称确认与门头照解耦的先例。
- **DR-2F09-VERIFY-20261025**：负责人声明 2F-09 归属「小吕哥黄焖鸡」作为确认依据落档。

### 共同后置（缺一不可）

1. **DR 落档**：谁、何时、确认范围、负面清单，格式沿 DR-2F09 先例；
2. **契约名册同步轮**：§5.5 / 入册条款 / 名册行 / §5.6.4 例外表 / B8 行 + 变更登记（波及面见 §五）；
3. **测试同步**：与契约同轮执行（见 §五）。

**门头照不是必要条件。** 负责人 2026-10-25 已裁决不补门头照；先例 `:868` 支持名称
确认与门头照解耦。门头照仍是转录稿 §8.3 条件 5 的独立事项，本 DRAFT 不触碰。
