# 投稿协议草稿（UGC 纠错投稿）

> 状态：**草稿，未经负责人确认，不构成对用户的要约，也不构成合规结论。**
> 说明：本协议只约束「纠错投稿」这一动作，不改变小程序既有《用户协议》与类目边界。

## 一、你提交的内容

1. 你提交的是**纠错信息**，不是发布内容；你没有、也不会获得直接发布或修改菜品数据的能力。
2. 你应尽量确保信息真实、可核对（例如：价目表照片上的价格、档口张贴的通知）。
3. 你不得提交违法、侵权、侮辱、广告、诱导、涉未成年人隐私或其他违反平台规范的内容。
4. 你不得提交他人的个人信息、联系方式或未经授权的图片（本版本不接收图片）。

## 二、我们怎么处理

1. 提交后进入**待审核**状态，只有管理员可见。
2. 管理员可以**通过**或**驳回**；通过仅表示「采纳这条纠错建议」，不代表菜品信息已被核实，也不代表允许公开。
3. 我们可能基于同一内容的重复提交做合并或拒绝，并记录处理结果。
4. 若内容安全检测未完成或判定为风险，该条不会被视为可通过。

## 三、你的授权范围

1. 你授权我们在**内部纠错核对**范围内使用你提交的内容。
2. 该授权**不包含**公开展示、对外发布、商业宣传或提供给第三方（法律要求或平台要求除外）。
3. 若未来需要公开使用，我们会另行取得你的同意，并先完成合规评估。

## 四、删除与撤回

1. 你可以要求删除自己提交的内容，渠道与时限**待确认**（当前无在线客服承诺）。
2. 删除后正文会被清除；依法必须保留的操作记录可能继续保存。
3. 已被采纳的纠错若已影响人工核对结论，删除不回溯已完成的内部处理记录。

## 五、责任边界

1. 我们不对「采纳建议后信息是否最终准确」作保证；核实是另一条独立流程。
2. 因你提交虚假、侵权内容导致的后果，由你承担相应责任；我们有权驳回并记录。
3. 本协议未尽事宜，以平台规则与法律法规为准。

## 六、生效条件

本协议在以下条件全部满足后才对真实用户生效，缺一不可：

- 隐私告知文案经负责人确认并同步到微信后台；
- 保存期限、删除渠道、联系方式三项补齐；
- UGC 场景声明与类目风险经负责人书面确认；
- 灰度范围限定为管理员/体验版，未对真实用户开放。
