## 三、结果判定表（每种结果意味着什么）

| 后台核查结果 | 含义 | 对路径 A（保留类目、非公开纠错）的影响 | 对路径 B（公开 UGC）的影响 |
|---|---|---|---|
| 文本 + 多媒体**均已获得** | 接口可直接调用 | **A 可进入开发**（仍需人工审核、隐私告知、投诉入口） | B 的前置条件之一满足 |
| 文本已获得，多媒体**需申请** | 图片链路未就绪 | **只能做纯文本纠错**：MVP 关闭图片上传；或等申请结果 | 图片类 UGC 不可上线 |
| 文本 + 多媒体**均需申请** | 权限待批 | A 暂停，先走申请；申请材料与时长决定下一步 | 同 |
| 接口**可见但不允许个人主体** | 主体限制 | **A 不可行**（5.18 要求有 UGC 即须检测） | 必须先变更主体（B） |
| 接口**完全不可见/无此权限项** | 账号无该能力 | **A 不可行**（同上） | 必须先解决主体或联系平台确认 |
| 配额未显示 / 版本未标注 | 信息不足 | 不阻塞 A 开发，但**上线前**须以官方客服或后台实际调用结果确认 | 同 |

> 判定原则：**「接口在文档里存在」不等于「本账号可用」**。只有后台权限状态为「已获得」才视为可用。
