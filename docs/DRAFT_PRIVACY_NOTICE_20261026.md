# 隐私告知文案草稿（UGC 纠错投稿）

> 状态：**草稿，未经负责人与法务确认，不得直接上线，也不构成合规结论。**
> 依据：`docs/UGC_MVP_DESIGN_FINAL_20261026.md` §6.9、`docs/UGC_MVP_COMPLIANCE_GAP_REVIEW_20261026.md` B3/B4/B5。
> 用途：给评审用的文案骨架；凡标「待确认」处，必须在负责人签字前补齐，否则该项视为未完成。

## 一、草稿正文（面向用户）

### 1. 这个功能是什么

「纠错投稿」用于把你在食堂看到的**价格或信息错误**告诉管理员。提交后由人工核对，**不会直接公开**，也不会让你的投稿出现在任何人的首页或搜索里。

### 2. 我们会收集什么

- 你填写的纠错内容：纠错类型、正确的价格或菜名建议、文字说明（≤100 字）；
- 你指出的对象编号：店铺、档口、菜品编号（用于定位，不包含你的位置）；
- 服务端自动记录：提交时间、审核结果、系统内部流水号。

**我们不收集**：微信昵称、头像、手机号、精确位置、通讯录、相册照片（本版本不开放图片上传）。

### 3. 为什么能识别到你

为了区分「谁提交的」并在你请求删除时找到对应记录，云函数会使用微信提供的**匿名标识（openid）**。该标识只保存在服务端，不在页面上展示，也不写进对外日志的明文里（日志中仅保存不可逆摘要）。

### 4. 内容会经过什么处理

1. 提交时先做自动内容安全检查（微信内容安全接口）；
2. 检查为「明确风险」或「接口故障」的内容不会进入可采纳状态；
3. 管理员在**仅管理员可用**的页面逐条查看，决定通过或驳回；
4. **通过只表示管理员采纳了这条纠错建议，不代表该菜品信息已被核实，更不代表允许公开或用于对外展示。**

### 5. 会公开吗

不会。至少在当前阶段，投稿内容只用于内部纠错核对，不进入任何公开数据源，也不会自动写入菜品库。

### 6. 保存多久

保存期限**待负责人确认**（不得默认写成 90 天）。确认前，本功能不得对真实用户开放。

### 7. 你的权利

- 你可以要求删除自己提交的内容；删除渠道与响应时限**待确认**（当前没有在线客服入口可供承诺）；
- 删除后，投稿正文会被清除，但依法必须保留的操作记录可能继续保存；
- 若你认为处理结果有误，可通过**待确认的反馈渠道**提出复核。

### 8. 不会用于什么

不用于营销推送、不用于用户画像、不向第三方出售或共享你的投稿内容（微信内容安全接口的处理除外，其处理规则以微信官方说明为准）。

### 9. 联系方式

运营主体、联系人、邮箱/电话：**待负责人填写**。
