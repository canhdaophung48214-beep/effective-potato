# 证据照片命名清单 · 服务楼 2 楼（`c01`）

> **这份是给「整理人」看的，不是给采集的群友看的。** 群友只要把原图发回来就行，命名由整理人统一做；群友看的是同目录下的 `采集卡.md`。

> 照片统一放在本目录下的 `img/` 里，CSV 的 `evidence_file` 写相对路径，例如 `img/c01_t01_menu.jpg`。
> 命名规则：**`<对象 id>_<类型>.jpg`**，类型只用四种：`menu`（价目表）/ `sign`（门头或楼层指引）/ `storefront`（门脸全貌）/ `price`（价格特写）。
> 一个文件可以对多条记录复用（同一张价目表覆盖该窗口所有菜），但**每条记录的 `evidence_file` 都必须填上**。

---

## 1. 必备三张（先拍这三张，后面所有记录都能用上）

| 建议文件名 | 拍什么 | 覆盖到哪些记录 |
|---|---|---|
| `img/c01_storefront.jpg` | 服务楼门脸 / 入口外观（能看到楼名） | `shops.csv` 的 `c01` |
| `img/c01_f1_sign.jpg` | 楼层指引牌 / 「2 楼」标识 | `floors.csv` 的 `c01_f1` |
| `img/c01_f1_menu.jpg` | 2 楼整体价目墙或导览牌（若存在） | 可复用到该层多个窗口 |

## 2. 每个窗口 1–2 张

| 建议文件名 | 拍什么 | 覆盖到哪些记录 |
|---|---|---|
| `img/c01_t01_menu.jpg` | 第 1 个窗口的**完整**价目表 | 该窗口的 `stalls.csv` 行 + 该窗口所有 `dishes.csv` 行 |
| `img/c01_t01_sign.jpg` | 窗口招牌（写清窗口叫什么） | 该窗口的 `stalls.csv` 行 |
| `img/c01_t01_price.jpg` | 价目表上的价格特写（字小/反光时补拍） | 该窗口价格看不清的那几道菜 |
| `img/c01_t02_menu.jpg` … | 第 2、3、4、5 个窗口同规则 | 同上 |

## 3. 什么时候需要单独记

- 一道菜的价格只出现在**另一个窗口**的小牌上（例如「红烧肉盖饭」在两个窗口都有）：两个窗口各记一行，各自填各自窗口的价目表照片
- 同一张价目表照片里能看到别的窗口的菜：**不要**拿它给别的窗口的菜当证据，容易张冠李戴
- 临时贴纸价（手写改价）：单独拍 `img/c01_t0N_price.jpg`，并在 `source_detail` 里写「手写改价贴纸」

## 4. 拍不全怎么办

- 价目表缺角、反光、拍不全 → **先补拍**，补不到就不录那几道菜
- 完全拍不到的窗口 → 本轮不建该窗口记录（宁缺勿凑）
- 照片与记录对不上 → 以照片为准，改记录；不要改照片名去迁就记录
